Solitaire Win

A screensaver for the Macintosh.
Version 1.0.0  ·  Released October 21, 2026  ·  348 KB  ·  Mac OS 13 or later  · 

This screensaver shows the screen that appears when a game of Solitaire is won. The cards leave the foundations one at a time, bounce along the bottom of the screen and leave a copy of themselves at every step. When all 52 cards are gone the foundations are refilled and it continues.

Installation

  1. Download Solitaire-Win.zip and unzip it.
  2. The screensaver is not notarised by Apple, and the Mac will block it the first time. In Terminal, enter:
    xattr -dr com.apple.quarantine ~/Downloads/"Solitaire Win.saver"
    Alternatively, double-click it, then go to System Settings → Privacy & Security and click Open Anyway.
  3. Double-click Solitaire Win.saver and choose to install it.
  4. Select Solitaire Win in System Settings → Screen Saver. Further settings are under Options….

Source code is on GitHub. Technical notes are also available.
