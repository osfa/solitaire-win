Install

Installing

  1. Download Solitaire-Win.zip and unzip it.

  2. It isn't notarised by Apple, so macOS will block it at first. Clear the download flag in Terminal:

    xattr -dr com.apple.quarantine ~/Downloads/"Solitaire Win.saver"

    Or double-click it, and when macOS refuses, open System Settings → Privacy & Security and click Open Anyway.

  3. Double-click Solitaire Win.saver and choose to install it.

  4. Pick Solitaire Win in System Settings → Screen Saver. Options… sets how fast it breaks, how far, and which kinds of trouble are allowed.
