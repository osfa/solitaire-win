Welcome! You know the screen you get when you win at Solitaire, with the cards bouncing off the piles and leaving trails all over the green felt? This screensaver plays it for you. For a minute or so it is exactly right. Then it starts to go wrong: slow motion, sudden bursts of speed, colours cycling, cards flying the wrong way, glitches. It gets worse and worse until the computer "reboots" and it starts all over again.

How to Install

  1. Download Solitaire-Win.zip and unzip it.
  2. It isn't notarised by Apple, so the Mac will block it the first time. Open Terminal and type:
    xattr -dr com.apple.quarantine ~/Downloads/"Solitaire Win.saver"
    Or double-click it, and when the Mac refuses, go to System Settings → Privacy & Security and click Open Anyway.
  3. Double-click Solitaire Win.saver and choose to install it.
  4. Pick Solitaire Win in System Settings → Screen Saver. The Options… button sets how fast it breaks, how far, and which kinds of trouble are allowed.
